# Резюме — персональный сайт

[English](README.md) · [Русский](README.ru.md)

Персональное портфолио и резюме на Preact и Vite. Страница содержит краткую информацию об авторе, навыки,
опыт работы, образование и ссылки на социальные сети. Поддерживаются русский и английский языки,
светлая и тёмная темы.

Сайт: [dosymep.net](https://dosymep.net) · [dosymep.github.io](https://dosymep.github.io)

Кнопка **Скачать резюме** открывает диалог печати браузера, в котором можно распечатать страницу
или сохранить её в PDF.

## Начало работы

Используйте Node.js 24 LTS (24.15 или новее), как в `.nvmrc` и GitHub Actions. Версия Yarn 4 закреплена
в поле `packageManager` файла `package.json`. Зависимости устанавливаются в обычный каталог `node_modules/`.

Установите Corepack и включите Yarn:

```bash
npm install --global corepack@0.36.0
corepack enable yarn
```

В корне репозитория установите зависимости и запустите сервер разработки:

```bash
yarn install --immutable
yarn dev
```

Команда установки использует сохранённый lock-файл без изменений. После редактирования зависимостей
в `package.json` выполните `yarn install` для обновления `yarn.lock` и сохраните оба файла в Git.

Откройте локальный адрес, указанный в терминале. Vite обновляет страницу при изменении исходных файлов.

## Команды

| Команда                            | Назначение                                    |
|------------------------------------|-----------------------------------------------|
| `yarn dev`                         | Запуск сервера разработки.                    |
| `yarn build`                       | Создание сборки для публикации в `public/`.   |
| `yarn preview`                     | Локальный просмотр готовой сборки.            |
| `yarn test`                        | Однократный запуск всех тестов.               |
| `yarn test:watch`                  | Повторный запуск тестов при изменении файлов. |
| `yarn test tests/settings.test.js` | Запуск только тестов настроек.                |

Для просмотра сборки перед публикацией:

```bash
yarn build
yarn preview
```

Каталог `public/` создаётся автоматически и исключён из Git. Для изменения сайта редактируйте исходные файлы.

## Содержимое и локализация

Тексты страницы находятся в [`src/resources/translations.json`](src/resources/translations.json),
в разделах `en` и `ru`. Каждая локаль содержит следующие разделы:

| Раздел     | Содержимое                                                            |
|------------|-----------------------------------------------------------------------|
| `page`     | Название вкладки браузера.                                            |
| `header`   | Описание логотипа, подпись переключателя языка и подписи кнопки темы. |
| `about`    | Приветствие, имя, биография, местоположение и подпись кнопки резюме.  |
| `features` | Заголовки разделов, опыт работы и образование.                        |
| `skills`   | Названия навыков и подписи кнопок раскрытия и сворачивания.           |
| `social`   | Подсказки и доступные названия ссылок.                                |
| `footer`   | Текст внизу страницы.                                                 |

При обновлении содержимого редактируйте соответствующие значения в обеих локалях. Сохраняйте одинаковые ключи
и соответствие элементов списков в переводах. Названия внутри каждого списка навыков должны быть уникальными.
Компоненты получают выбранный перевод через `content` в `SettingsContext`.

Переключение языка обновляет содержимое страницы, описания изображений, подписи ссылок, название вкладки
и атрибут HTML `lang`. Исходный HTML содержит метаданные на русском языке; при запуске приложение
применяет выбранную локаль.

Для добавления языка также нужно обновить определение и переключение языка в
[`src/lib/settings.js`](src/lib/settings.js) и
[`src/components/settings/index.jsx`](src/components/settings/index.jsx), а также подписи кнопки языка и тесты.

Адреса социальных ссылок задаются в [`src/components/social/index.jsx`](src/components/social/index.jsx).
Статические изображения и значок сайта находятся в `src/assets/`, SVG-иконки — в `src/icons/`.

## Настройки языка и темы

При каждой загрузке страницы сохранённый выбор имеет приоритет над настройками браузера.
Если выбор не сохранён:

- **Язык:** используется первый поддерживаемый язык из `navigator.languages`. Региональные варианты,
  например `ru-RU` и `en-US`, сопоставляются с `ru` и `en`. Если список языков недоступен или пуст,
  приложение проверяет `navigator.language`. Если поддерживаемый язык не найден, используется английский.
- **Тема:** настройка `prefers-color-scheme` определяет, нужно ли включить тёмную тему.
  По умолчанию используется светлая тема.

Ручные изменения сохраняются в `localStorage` под ключом `settings` в виде именованных значений:

```json
{
  "theme": "dark",
  "locale": "en"
}
```

Для `theme` поддерживаются значения `light` и `dark`, для `locale` — `ru` и `en`.
Сохраняются только настройки, выбранные вручную. Изменение темы оставляет язык в автоматическом режиме,
а изменение языка оставляет автоматический выбор темы, если другая настройка не была сохранена ранее.

Автоматический выбор пересчитывается при следующей загрузке страницы. Ранее сохранённые булевы настройки (`dark` и
`eng`) преобразуются в именованный формат при запуске приложения. Вместо некорректных сохранённых
значений используются настройки браузера. Если доступ к хранилищу заблокирован, ручные изменения
действуют в текущем сеансе страницы.

Для сброса обеих настроек выполните в консоли браузера на сайте:

```js
localStorage.removeItem('settings')
location.reload()
```

## Тестирование

Все тесты находятся в [`tests/`](tests/). Набор тестов запускается с помощью Vitest,
а Preact Testing Library и jsdom обеспечивают отрисовку компонентов и взаимодействие с DOM.

Тесты проверяют:

- Определение настроек браузера, независимое сохранение выбора, прежний формат настроек и недоступность хранилища.
- Переключение языка и темы, сохранённые настройки и метаданные страницы.
- Раскрытие разделов и списков навыков, включая смену языка при раскрытом списке.
- Адреса социальных ссылок и их доступные названия.
- Вызов диалога печати браузера кнопкой резюме.
- Загрузку SVG и замену иконок.
- Структуру переводов, непустые тексты и уникальность названий навыков.

Общие настройки браузера для тестов и очистка после их выполнения заданы в `tests/setup.js`.
Добавляйте новые тесты в `tests/` с суффиксом `.test.js` или `.test.jsx`.
Тесты DOM проверяют поведение; вёрстку, внешний вид и результат печати проверяйте в браузере.

## Публикация и обновление зависимостей

Процесс [`main`](.github/workflows/main.yml) запускает тесты и сборку для запросов на слияние в `main`,
при отправке изменений в `main` и при ручном запуске. Задание сборки использует Node.js из `.nvmrc`,
Corepack и `yarn install --immutable`, затем загружает `public/` как артефакт. Отдельное задание публикации
скачивает этот артефакт и публикует его в `gh-pages` только после отправки изменений в `main` или ручного запуска
на `main`. Запросы на слияние не запускают публикацию. Право записи в репозиторий предоставлено только
заданию публикации.

[`Dependabot`](.github/dependabot.yml) проверяет обновления GitHub Actions и зависимостей JavaScript каждую среду.
Обновления JavaScript охватывают `package.json` и `yarn.lock`, включая зависимости для разработки.
Обновления группируются отдельно по экосистемам; запросы на слияние создаются в ветку `main`.
